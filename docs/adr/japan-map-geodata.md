# 地図の県境は Natural Earth（パブリックドメイン）を簡略化して同梱する

## 背景

spec `prefecture-picker` は日本地図から都道府県を選ばせる。
「日本の形として認識できること」が要件であり、これは格子や円の組み合わせでは満たせない
（実際に両方を試作して、いずれも階段状・ブロブ状にしかならないことを確認した）。
実測の県境ポリゴンが要る。

ui-labo は MIT で公開し、利用者が商用アプリに組み込むことを想定している。
**ライブラリに同梱するデータは、利用者に追加の義務を課さないものでなければならない。**

## 決定

**Natural Earth の `ne_10m_admin_1_states_provinces`** を出典とする。

1. `npm run sync:geo` を明示実行したときだけ配布元（naciscdn.org）から取得する
2. 取得した shapefile から `adm0_a3 == "JPN"` の 47 件を抽出する。
   `iso_3166_2`（`JP-01`〜`JP-47`）の数値部が JIS X 0401 の都道府県コードと一致する
3. 簡略化・平滑化・投影し、`packages/data/src/japan-outline.json` に書き出して**コミットする**
4. 通常のビルドは配布元に触れない。**元データ（15MB）はコミットしない**

## 理由

- **パブリックドメインである。** 配布元の利用条件に次のとおり明記されている。

  > All versions of Natural Earth raster + vector map data found on this website are in
  > the public domain. You may use the maps in any manner, including modifying the content
  > and design, electronic dissemination, and offset printing. ...
  > No permission is needed to use Natural Earth. Crediting the authors is unnecessary.

  出典明記も利用報告も不要なので、MIT ライブラリに同梱しても
  **利用者に一切の義務が伝播しない**。これが決め手。
- 47 都道府県が `JP-01`〜`JP-47` で過不足なく揃っていることを実データで確認済み。
  日本語名（`name_ja`）も入っている。
- 1:10m は国別地図としては粗いが、本コンポーネントは概略図しか必要としない。
  むしろ簡略化の手間が減る。

## 検討して捨てた選択肢

### 座標と面積からの自作生成（第三者データを一切使わない）

県庁所在地の緯度経度・県面積・主要都市の座標という**事実データだけ**から、
面積相応の円と島内の連結帯で陸地を作り、最近傍分割（ボロノイ）で県界を得る方式を実装し、
実際に描画して確認した。

**結果は不採用。** 本州がつながらず、丸い塊の連なりにしかならない。
47 点の座標には海岸線の情報が含まれておらず、これは調整では解決しない。
生成器は `tools/` に残さず破棄した。

### `dataofjapan/land` の `japan.geojson`

最初に採用しかけたが、**LICENSE ファイルが存在しない**（リポジトリに 404）。
README に次の記載がある。

> ライセンスは配布元に準じ、非営利目的の場合は「出典元(地球地図日本)の明記」を、
> 営利目的の場合は「出典元(地球地図日本)の明記」と「著作権者(地球地図日本)への利用報告」を
> お願いいたします。

MIT ライブラリに同梱すると、**利用者が商用で使うたびに第三者への利用報告義務が生じる**。
ライブラリとして成立しないため不採用。

### 国土数値情報・地球地図日本を直接使う

出典明記が必要で、地球地図日本は商用時の利用報告も求められる。上と同じ理由で不採用。

## 影響とトレードオフ

- 生成物は約 4,500 頂点・56KB。ライブラリの重量として許容範囲。
- 1:10m のため、細かい入り組んだ海岸線は再現されない。仕様上それでよい（概略図）。
- 取得と利用を分けているため、通常ビルドはオフラインで通る。
  配布元が消えてもスナップショットで配布を継続できる。
- 出典明記は**義務ではない**が、リポジトリの README には出典を書く。
  礼儀であり、次に触る人がデータの素性を追えるようにするため。

## 再検討の条件

- 1:10m の粗さが実際に問題になった場合（離島の欠落が指摘される等）。
  Natural Earth の 1:50m / 1:110m は逆に粗く、より細かいものは別出典を探すことになる。
- Natural Earth の利用条件が変わった場合。**採用理由がパブリックドメインである一点なので、
  ここが崩れたら即座に見直す。**
- 日本の行政区画そのものが変わった場合（都道府県の統廃合）。
